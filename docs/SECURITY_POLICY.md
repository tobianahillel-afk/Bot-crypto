# Security Policy — Lot 0

Règles obligatoires :

- Aucune clé API avec permission withdrawal.
- Secrets jamais committés.
- `.env` interdit dans Git.
- Clés séparées data/trading.
- Lecture seule par défaut.
- Trading réel désactivé au Lot 0.
- Aucune clé réelle n’est demandée.
- Aucun appel réel à Kraken n’est effectué.
