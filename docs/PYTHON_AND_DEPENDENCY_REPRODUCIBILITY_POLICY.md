# Python and Dependency Reproducibility Policy

## Canonical runtime

The evidence environment is:

```text
CPython 3.11.9
Ubuntu runner
UTC
```

`pyproject.toml` allows only the Python 3.11 family. Compatibility with another Python version
requires a separate non-canonical CI job and an explicit promotion decision.

## Files

- `.python-version` — local canonical interpreter;
- `requirements-dev.in` — direct quality-tool dependencies pinned exactly;
- `requirements-dev.lock` — complete transitive environment generated by `pip freeze`;
- `requirements-dev.txt` — compatibility include of the lock.

## Update process

1. modify `requirements-dev.in`;
2. resolve on Python 3.11.9;
3. generate a new sorted lock;
4. run `pip-audit`;
5. run all CI gates;
6. document versions and rollback in the PR.

No unreviewed `>=` dependency is installed in CI.

## Release evidence

A release records Python version, lock checksum, config checksums, source commit and test artifacts.
