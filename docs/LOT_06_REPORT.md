# Lot 6 Report — Market Regime Engine V1

Lot 6 adds a first deterministic market regime layer based on existing datasets from Lots 2 to 5.

Generated objects:

```text
RegimePoint 5m
RegimePoint 15m
```

Generated datasets:

```text
data/gold/btc_eur_5m_regime_lot6.jsonl
data/gold/btc_eur_15m_regime_lot6.jsonl
```

Lot 6 does not add trading, strategy, backtest, WebSocket, API, paper trading, ML, AI/news, live execution, target, label or future_* feature.
